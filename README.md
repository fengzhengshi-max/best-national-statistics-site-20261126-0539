NationScope: World Statistics Explorer — ranks the 30 most populous countries on eight World Bank indicators (2023): population, GDP, GDP per capita, life expectancy, schooling, internet use, CO2 per capita and land area. Sortable rankings, a top-10 chart, a country detail page with a world-average comparison, an indicator glossary and a sources page — all static files, no network requests. Built by an AI agent for make.fun's “Make the best national statistics site” bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser (desktop or phone size).
